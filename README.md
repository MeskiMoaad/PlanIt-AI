# 🚀 PLANIT AI

### Smart Project Planning & Development

---

## 📌 Project Overview

PLANIT AI is a web application designed to simplify the planning and organization of development projects. It aims to generate structured development plans based on information provided by the user.

## 🛠️ Current Development Status

The project is currently in its first JavaScript development phase.

### ✅ Implemented Features

- Set up the basic project structure.
- Connected JavaScript files to HTML using ES6 modules.
- Created a JSON file containing a sample development plan (`sample-plan.json`).
- Implemented an initial Fetch API request to retrieve JSON data.
- Added error handling using `.then()` and `.catch()`.
- Checked HTTP responses using `response.ok`.
- Converted JSON responses into JavaScript objects using `response.json()`.

### 📁 Current Project Structure

```text
PLANIT-AI/
├── index.html
├── newProject.html
├── main.js
├── demo.js
└── sample-plan.json
```

## 💻 Technologies Used

- HTML5
- Tailwind CSS
- JavaScript (ES6 Modules)
- Fetch API
- JSON

## 🧪 Demo Mode

Demo Mode uses `sample-plan.json` as a data source to simulate a development plan generated by an AI system.

The data is retrieved using Fetch API and then processed with JavaScript.

## ⚙️ Getting Started

1. Clone or download the repository.
2. Open the project in Visual Studio Code.
3. Launch `newProject.html` or `dashboard.html` using the Live Server extension.
4. Open your browser to test the application.
